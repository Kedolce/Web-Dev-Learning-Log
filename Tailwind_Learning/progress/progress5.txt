=================================================
HARI 5 - JAVASCRIPT DOM (LANJUTAN)
=================================================

Tujuan:
Memahami cara memanipulasi isi, tampilan, class, serta membuat dan menghapus elemen HTML secara dinamis menggunakan JavaScript.

=================================================
1. getElementById()
=================================================

Fungsi:
Mengambil (memilih) elemen HTML berdasarkan atribut id.

Sintaks:

document.getElementById("namaId");

Contoh:

const judul = document.getElementById("judul");

Cara Kerja:
- Browser mencari elemen yang memiliki id sesuai.
- Jika ditemukan, elemen tersebut dikembalikan.
- Jika tidak ditemukan, akan menghasilkan null.

Kapan Digunakan:
- Ketika ingin mengambil elemen yang unik.
- Karena id seharusnya hanya dimiliki oleh satu elemen.

Kapan Tidak Digunakan:
- Jika ingin mengambil banyak elemen sekaligus.
- Jika ingin menggunakan selector CSS yang lebih kompleks.

Perbandingan:

getElementById("judul")
↓
Khusus mencari id.
Tidak perlu #.

querySelector("#judul")
↓
Bisa mencari id, class, tag, dan selector CSS lainnya.
Harus menggunakan # untuk id.

Contoh Penerapan:
- Tombol submit.
- Judul halaman.
- Form login.

Kesalahan Umum:
❌ document.getElementById("#judul")
✅ document.getElementById("judul")

=================================================
2. textContent
=================================================

Fungsi:
Mengambil atau mengubah teks pada suatu elemen.

Sintaks:

element.textContent

atau

element.textContent = "Teks Baru";

Contoh:

judul.textContent = "Belajar JavaScript";

Cara Kerja:
- Jika dibaca → mengambil isi teks.
- Jika diubah → mengganti seluruh isi teks.

Kapan Digunakan:
- Mengubah tulisan.
- Menampilkan hasil input pengguna.
- Counter.

Kapan Tidak Digunakan:
- Jika ingin menambahkan tag HTML.

Contoh:

judul.textContent = "<h1>Hello</h1>";

Output:

<h1>Hello</h1>

(Tag dianggap sebagai teks biasa.)

Perbandingan:

textContent
↓
Hanya memproses teks.

innerHTML
↓
Memproses HTML.

Contoh Penerapan:
- Live preview.
- Counter karakter.
- Menampilkan skor.

Kesalahan Umum:
Mengira textContent dapat membuat tag HTML.

=================================================
3. innerHTML
=================================================

Fungsi:
Mengambil atau mengubah isi HTML suatu elemen.

Sintaks:

element.innerHTML

atau

element.innerHTML = "<p>Hello</p>";

Cara Kerja:
- Browser membaca string HTML.
- Browser membuat elemen HTML berdasarkan string tersebut.

Contoh:

container.innerHTML = `
    <h2>Belajar DOM</h2>
    <p>Saya sedang belajar innerHTML</p>
`;

Kapan Digunakan:
- Menambahkan HTML sederhana.
- Membuat tampilan cepat.

Kapan Tidak Digunakan:
- Jika membuat banyak elemen dinamis.
- Jika data berasal dari pengguna (alasan keamanan).

Perbandingan:

innerHTML
↓
Bisa membaca dan membuat HTML.

textContent
↓
Hanya teks.

Penting:

container.innerHTML = ...
↓
Mengganti seluruh isi lama.

container.innerHTML += ...
↓
Menambahkan isi baru.

Contoh Penerapan:
- Menampilkan kartu produk.
- Menampilkan komentar.

Kesalahan Umum:
❌ Menggunakan petik biasa untuk multiline.

Salah:

container.innerHTML = "
<h1>Hello</h1>
";

Benar:

container.innerHTML = `
<h1>Hello</h1>
`;

=================================================
4. style
=================================================

Fungsi:
Mengubah CSS secara langsung melalui JavaScript.

Sintaks:

element.style.property = "value";

Contoh:

judul.style.color = "white";
judul.style.backgroundColor = "blue";
judul.style.fontSize = "40px";

Cara Kerja:
JavaScript menambahkan inline CSS.

Contoh hasil:

<h1 style="color:white;"></h1>

Kapan Digunakan:
- Mengubah tampilan secara dinamis.
- Animasi sederhana.
- Menyembunyikan elemen.

Kapan Tidak Digunakan:
- Jika menggunakan banyak style.
- Jika menggunakan Tailwind.

Perbandingan:

style
↓
Mengubah CSS secara langsung.

classList
↓
Menambah atau menghapus class.

Penting:
CSS di JavaScript menggunakan camelCase.

Contoh:

background-color
↓
backgroundColor

font-size
↓
fontSize

Contoh Penerapan:
- Mengubah warna tombol.
- Animasi.
- Drag and drop.

Kesalahan Umum:

❌ judul.style.background-color = "red";
✅ judul.style.backgroundColor = "red";

=================================================
5. classList
=================================================

Fungsi:
Memanipulasi class CSS pada suatu elemen.

Method yang Dipelajari:

1. add()
Menambahkan class.

element.classList.add("bg-blue-500");

2. remove()
Menghapus class.

element.classList.remove("hidden");

3. toggle()
Jika class ada → hapus.
Jika class tidak ada → tambahkan.

element.classList.toggle("hidden");

4. contains()
Mengecek keberadaan class.

element.classList.contains("hidden");

Cara Kerja:
JavaScript mengubah atribut class pada HTML.

Kapan Digunakan:
- Sangat sering dipakai bersama Tailwind.
- Navbar mobile.
- Modal.
- Sidebar.
- Dark mode.

Kapan Tidak Digunakan:
- Jika nilai CSS berubah terus-menerus (misal posisi pixel).

Perbandingan:

style
↓
Langsung mengubah CSS.

classList
↓
Mengubah class CSS.

Contoh Penerapan:
- Dark mode.
- Dropdown.
- Navbar mobile.

Kesalahan Umum:

❌ classList.add(".bg-blue-500")
✅ classList.add("bg-blue-500")

=================================================
6. createElement()
=================================================

Fungsi:
Membuat elemen HTML baru melalui JavaScript.

Sintaks:

document.createElement("tag");

Contoh:

const p = document.createElement("p");

Cara Kerja:
- Browser membuat elemen baru di memori.
- Elemen belum tampil di browser.

Kapan Digunakan:
- Todo List.
- Chat App.
- Komentar.
- Daftar produk.

Kapan Tidak Digunakan:
- Jika elemen sudah tersedia di HTML.

Penting:
Elemen yang dibuat belum muncul di browser.

Harus digabung dengan:

appendChild()

Contoh Penerapan:
- Menambah item todo.
- Menambah pesan chat.

Kesalahan Umum:

❌ createElement("p")
✅ document.createElement("p")

=================================================
7. appendChild()
=================================================

Fungsi:
Menambahkan elemen ke dalam DOM.

Sintaks:

parent.appendChild(child);

Contoh:

container.appendChild(p);

Cara Kerja:
- Parent menerima child.
- Child ditambahkan di bagian paling bawah.

Kombinasi yang Sangat Sering:

createElement()
+
textContent
+
classList
+
appendChild()

Contoh:

const p = document.createElement("p");

p.textContent = "Hello";

p.classList.add("bg-green-500");

container.appendChild(p);

Kapan Digunakan:
- Todo List.
- Chat App.
- Komentar.

Perbandingan:

appendChild()
↓
Menambah elemen DOM.

innerHTML
↓
Menggunakan string HTML.

Kesalahan Umum:

❌ p.appendChild(container)
✅ container.appendChild(p)

=================================================
8. remove()
=================================================

Fungsi:
Menghapus elemen dari DOM.

Sintaks:

element.remove();

Contoh:

pesan.remove();

Cara Kerja:
Elemen yang memanggil remove() akan menghapus dirinya sendiri dari DOM.

Contoh:

pesan.remove();

↓

Elemen pesan hilang dari halaman.

Kapan Digunakan:
- Menghapus todo.
- Menghapus notifikasi.
- Menutup modal.

Kapan Tidak Digunakan:
- Jika elemen hanya ingin disembunyikan sementara.

Lebih baik:

element.classList.add("hidden");

Perbedaan:

remove()
↓
Elemen benar-benar hilang.

hidden
↓
Elemen hanya disembunyikan.

Kesalahan Umum:

❌ remove(pesan)
❌ container.remove(pesan)

✅ pesan.remove()

Penting:
remove() tidak membutuhkan parameter.

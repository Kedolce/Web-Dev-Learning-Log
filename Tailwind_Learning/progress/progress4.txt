2. npm install

3. npm install tailwindcss @tailwindcss/vite

4. buat file vite.config.js dan diisi:
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [tailwindcss()],
})

5. hapus semua isi style.css di src dan diisi: 
@import "tailwindcss";

6. npm run dev

7. main.js diisi: 
import './style.css'


**karena gw maunya beda2 file exercise tiap hari. jadi setiap buat file html baru paling bawah sebelum </body> dikasi script ini:

Jika file berada di:

exercise/day4.html

maka Vite tidak otomatis memasukkan:

src/main.js

ke halaman tersebut. Jadi di dalam body, tambahkan:

<script type="module" src="/src/main.js"></script>

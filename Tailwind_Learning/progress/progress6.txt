# Day 6 - JavaScript Event

Tanggal: 25 Juni 2026

## Materi yang Dipelajari

### Konsep Dasar Event

* Memahami apa itu Event dalam JavaScript.
* Memahami bagaimana browser menangani Event.
* Memahami konsep Event-Driven Programming.

### addEventListener()

* Memahami fungsi `addEventListener()`.
* Memahami alasan penggunaan `addEventListener()` dibanding `onclick`.
* Memahami bahwa browser akan menjalankan callback ketika event terjadi.

### Callback Function

* Memahami konsep Callback Function.
* Memahami perbedaan antara:

  * `tampil`
  * `tampil()`
* Memahami bahwa callback akan dipanggil oleh browser ketika event terjadi.

### Event Object

Mempelajari dan memahami:

* `event`
* `e`
* `event.target`
* `event.type`
* `event.key`
* `event.target.value`

### Event yang Dipelajari

* `click`
* `submit`
* `input`
* `change`
* `keydown`
* `keyup`
* `focus`
* `blur`
* `dblclick`
* `mouseenter`
* `mouseleave`

### preventDefault()

* Memahami fungsi `event.preventDefault()`.
* Mencegah perilaku default browser seperti refresh halaman saat submit form.

## Praktik yang Dilakukan

* Membuat event `click` pada tombol.
* Membuat event `submit` pada form.
* Mengambil nilai input menggunakan `.value`.
* Menampilkan data input ke console.
* Menerapkan validasi sederhana menggunakan event `blur`.
* Membedakan penggunaan `input` dan `change`.
* Membedakan penggunaan `keydown` dan `keyup`.
* Menerapkan `mouseenter` dan `mouseleave` pada studi kasus dropdown.
* Menerapkan `preventDefault()` pada form login.

## Hal Penting yang Dipahami

* Browser bekerja berdasarkan Event.
* Event hanya akan dijalankan ketika event tersebut terjadi.
* `event.target` mengacu pada elemen yang memicu event.
* Tidak semua event membutuhkan `preventDefault()`.
* Event yang berbeda digunakan untuk kebutuhan yang berbeda.
* Pemilihan event yang tepat sangat penting dalam pengembangan aplikasi web.
